# Roadmap

This document describes the future development plans and improvements
for DiscordBot.

The roadmap may change as the project grows and new requirements appear.

---

## Completed

The following features have already been implemented:

- [x] TypeScript based architecture
- [x] Discord.js v14 integration
- [x] Modular command system
- [x] Dynamic event loading
- [x] Command deployment system
- [x] Dependency injection container
- [x] Configuration management
- [x] Logging system
- [x] Code formatting with Prettier
- [x] Code quality checks with ESLint

---

## Long-Term Goals

The goal of this project is to build a scalable and maintainable
Discord bot framework that can support new features without requiring
major architectural changes.
